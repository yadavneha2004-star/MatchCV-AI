\# 📄 MatchCV-AI: Intelligent Resume Matcher \& Classifier



An end-to-end automated system built with Python and Flask that analyzes, parses, and ranks candidate resumes against target job descriptions using Natural Language Processing (NLP) scoring metrics.



\## 🚀 Live Demo

\[Live Demo](https://ai-job-app-ij1y.onrender.com)



\## ✨ Key Capabilities

\- \*\*Automated Score Analysis:\*\* Calculates content match ratios using TF-IDF text representation and Cosine Similarity metrics.

\- \*\*Key Skill Detection:\*\* Extracts relevant technical skills and mandatory qualifications directly from document text.

\- \*\*Cross-Format Support:\*\* Ingests document data from PDF (`.pdf`), Microsoft Word (`.docx`), and plain text (`.txt`) files.

\- \*\*Interactive UI:\*\* Provides a responsive dashboard equipped with real-time feedback indicator animations.

\- \*\*Batch Processing:\*\* Allows simultaneous upload and evaluation of multiple resume files.



\## 🛠️ Tech Stack \& Dependencies

\- \*\*Core Framework:\*\* Python, Flask

\- \*\*Data Science \& NLP:\*\* Scikit-Learn (TF-IDF Vectorization), Regex

\- \*\*Document Parsing:\*\* `pdfplumber`, `python-docx`

\- \*\*User Interface:\*\* HTML5, Modern CSS3, JavaScript (Fetch API)
